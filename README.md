# BEEZARD

Prototype interactif inspiré de la maquette Figma BEEZARD, consacré aux biomatériaux et aux matières issues du vivant.

## Développement

```bash
npm install
npm run dev
```

## Vérifications

```bash
npm test
npm run coverage
npm run test:e2e
npm run build
```

## Déploiement Netlify

Le dépôt contient `netlify.toml`. Netlify peut donc détecter automatiquement :

- commande de build : `npm run build`
- dossier publié : `dist`
- version de Node : 22
